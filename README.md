## 📂 Proyectos Destacados

### 1. 🚕 Urban Routes — Pruebas Web y Automatización E2E
Pruebas funcionales y automatización de flujos críticos de usuario (solicitud de viaje, selección de tarifas, métodos de pago y validación de formularios).

* **Enfoque:** Diseño de casos de prueba, pruebas de regresión y automatización bajo el patrón Page Object Model (POM).
* **Tecnologías:** Python, Pytest, Selenium WebDriver, Chrome DevTools.
* **Entregables en este repo:**
  * 📄 [Matriz de Casos de Prueba](./urban-routes/test-cases.md)
  * 💻 [Código de Automatización](./urban-routes/tests/)
  * 🐞 [Ejemplos de Reportes de Bugs](./urban-routes/bug-reports.md)

### 2. 🛒 Urban Grocers — Validación de API REST y Base de Datos
Verificación de endpoints para la creación de kits, gestión de usuarios y validación de reglas de negocio en el backend.

* **Enfoque:** Pruebas positivas/negativas, validación de códigos de estado HTTP (200, 400, 404, 500), estructura de respuestas JSON y persistencia en BD.
* **Tecnologías:** Postman, Python, Pytest, PostgreSQL.
* **Entregables en este repo:**
  * 📮 [Colección de Postman (.json)](./urban-grocers/postman_collection.json)
  * 💻 [Pruebas Automatizadas de API](./urban-grocers/api_tests.py)
  * 🗄️ [Consultas SQL de Validación](./urban-grocers/queries.sql)

### 3. 🛴 Urban Scooter — Testing Integral (Móvil, Web y API)
Proyecto integral de certificación abarcando el ciclo completo de QA para una plataforma de alquiler de scooters.

* **Enfoque:** Análisis de requisitos, creación de mapas mentales, checklists de pruebas en emulador Android y validación de endpoints.
* **Tecnologías:** Android Studio, Postman, Jira, SQL.
* **Entregables en este repo:**
  * 🧠 [Mapa Mental y Checklist de Pruebas](./urban-scooter/checklist.md)
  * 📱 [Evidencia de Pruebas Móviles y Reportes de Defectos](./urban-scooter/bugs.md)
